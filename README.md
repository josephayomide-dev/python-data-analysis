# Iris Flower Data Analysis with Python

## Project Overview
This project explores the Iris flower dataset using Python. The goal is to understand the dataset, compare flower species, and visualize the relationship between petal length and petal width.

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Work Completed
- Loaded the Iris dataset into a Pandas DataFrame.
- Inspected the dataset's dimensions and species distribution.
- Generated descriptive statistics.
- Created a scatter plot comparing petal length and petal width across species.
- Calculated average petal measurements for each species.

## Key Findings
- Setosa has the smallest average petal measurements.
- Virginica has the largest average petal measurements.
- Versicolor falls between the other two species.
- Petal measurements help distinguish the three species.

## What I Learned
This project helped me practise data loading, exploratory data analysis, summary statistics, visualization, and communicating findings using Python.

## How to Run
Open the `.ipynb` notebook in Google Colab or Jupyter Notebook and run the cells in order.
